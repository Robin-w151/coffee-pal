# 10: List and navigation wrappers

**Epic:** [0001 Migrate to Skeleton v5, Tailwind v4 and SvelteKit 3](README.md)
**Owner:** Claude
**Status:** Todo
**Depends on:** 07, 08
**Size:** M — five wrappers; Combobox is the tricky one, because v2 splits it into input + popup + `Autocomplete` list and the wrapper must own all three.

## User story

As Claude, I want the remaining Skeleton components behind app-owned wrappers, so that after this story no app code outside `ui/` imports Skeleton.
